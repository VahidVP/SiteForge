# Shop Sample

Generated by SiteForge.

## Run the frontend

```
cd frontend
npm install
npm run dev
```

Open http://localhost:5173 — API calls are proxied to the backend on port 8000.

**Admin access:** the very first account you register becomes the site owner (admin).
Sign in with it and open `/admin` to manage users, products and messages.

## Run the backend (ASP.NET Core)

Requires the .NET 8 SDK.

```
cd backend
dotnet run
```

The database is created and seeded automatically at http://localhost:8000.
Interactive API docs: http://localhost:8000/swagger
