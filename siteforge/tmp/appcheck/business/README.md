# App Check

Generated by SiteForge.

## Run the frontend

```
cd frontend
npm install
npm run dev
```

Open http://localhost:5173 — API calls are proxied to the backend on port 8000.

## Run the backend (Django)

```
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py makemigrations
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

There is also a full admin panel at http://localhost:8000/admin/ — create a login with:

```
python manage.py createsuperuser
```

(or simply register through the website — the first account is an admin automatically).
